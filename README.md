# AniTracker 追迹 - 完整交付报告

## 一、项目概述

AniTracker（追迹）是一个基于 Web 的番剧追剧管理工具，具备以下核心功能：
- 番剧列表管理
- 集数进度标记
- 灌水/半原创集识别
- 类型自动分类（漫改/TV原创/半原创）
- Bangumi 数据同步
- Filler Guide 灌水池校准
- WebDAV 云同步

## 五、使用说明

### 5.1 基本操作

1. **添加番剧**：点击右上角 ＋ → 输入番名搜索 → 选择 Bangumi 结果
2. **标记进度**：点击集数按钮切换状态
3. **筛选类型**：点击筛选按钮按类型过滤
4. **校准灌水**：在番剧详情页点击"校准灌水池"

### 5.2 高级功能

- **Bangumi 同步**：设置 → 粘贴 access_token
- **云同步**：设置 → 配置 WebDAV 地址
- **数据备份**：设置 → 导出全部数据
