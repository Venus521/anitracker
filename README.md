# AniTracker 追迹 - 完整交付报告

## 一、项目概述

AniTracker（追迹）是一个基于 Web 的番剧追剧管理工具，具备以下核心功能：
- 番剧列表管理
- 集数进度标记
- 灌水/半原创集识别
- 类型自动分类（漫改/TV原创/半原创）
- Bangumi 数据同步
- Filler Guide 灌水池校准
- WebDAV 云同步

## 五、使用说明

### 5.1 基本操作

1. **添加番剧**：点击右上角 ＋ → 输入番名搜索 → 选择 Bangumi 结果
2. **标记进度**：点击集数按钮切换状态
3. **筛选类型**：点击筛选按钮按类型过滤
4. **校准灌水**：在番剧详情页点击"校准灌水池"

### 5.2 高级功能

- **Bangumi 同步**：设置 → 粘贴 access_token
- **云同步**：设置 → 配置 WebDAV 地址
- **数据备份**：设置 → 导出全部数据

## v2.8.0（2026-09-24）同步修复 + TV原创数据集扩充

**修复「同步做不好」**
- 根因：`api.bgm.tv` 国内直连不通；原「公共 CORS 代理兜底」两个代理均已失效
  → 每次请求干等 13 秒后报一句含糊的「网络不可达」
- 直连超时 13s → 4s；移除已死代理；失败诊断改为「请开代理软件并启用系统代理/TUN」，可照做
- `BGMSYNC` 由 false 恢复 true，拉取/推送 Bangumi 按钮回归
- 新增可选「CORS 中继」设置（进阶）

> 认知修正：浏览器 `fetch` 无法指定 HTTP 代理，初版的「用户自填代理」方案已废弃。

**修复「TV原创标注做不好」**
- 根因：原数据集来自已停更的 animefillerguide.com，仅 58 部且不含柯南
- 改用 `animefillerlist.com`，全量爬取 **212 部**（+265%）：TV原创 3504 集 / 半原创 2610 集
- 柯南 575 集、死神 163 集、火影 90 集、海贼王 94 集 全部命中
- 别名表扩充至 80+ 条 + 中英文松散兜底匹配（`fgLooseMatch`）
- **新增联网实时抓取**（`fgFetchSlug`/`fgParseAfl`）：本地未收录的新番可一键抓取并缓存，
  解决「以后新番怎么办」
