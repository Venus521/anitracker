「无剧集数据 / 用不了」已修复

详情页统计全 0、来源覆盖显示「无剧集数据」、横幅却说「✓ 本作集全部标记过了」——这是空数据条目被误判的显示 bug。本页说明根因、修复内容与验证结果。v2.4.1 · build 20260914c

现象（你截图里看到的）

统计卡 0 / 0 / 0 / 0%；来源覆盖 「无剧集数据」；横幅 「✓ 本作集全部标记过了」；剧集区 「没有匹配的集」——条目完全无法标记进度。

根因

问题位置后果
B站追番导入的条目没有集数字段syncFromPortal产生 total=0、eps=[] 的空条目
手动添加留空集数 → total=0manualAdd同样是空条目（输入合法，但无后续路径）
空数据被误判为「全部标记过了」renderDetail 下一集按钮误导横幅（空列表找不到未看集 ≠ 都看完了）
关联 Bangumi 后不自动拉剧集assocPick即使关联了，条目仍是空的

在线搜索添加路径本身有保护（拉取失败不入库），不受影响。

修复内容

  • 关联后自动补齐：关联 Bangumi 成功 → 自动拉取该剧全集并填充，立刻可以标记进度（新增共用拉取管线，搜索添加与关联补齐走同一条数据路径）。
  • 空数据一键恢复：空条目详情页横幅改为「⚠ 此条目还没有剧集数据——点这里自动拉取（已关联 Bangumi），或用「✎ 编辑集数」手动补」，点横幅即可重试。
  • 来源覆盖行：无数据时追加「关联 Bangumi 补齐剧集 ›」入口（未关联会先弹出关联搜索）。
  • 空态文案纠错：剧集区区分「暂无剧集数据」（给恢复指引）与「没有匹配的集」（真筛选无结果）。
  • 提示补全：手动添加 0 集与 B 站导入完成的提示里加入指引。
  • 版本：页面 2.4.1 / build 20260914c；SW 缓存 anitracker-v5（保证客户端能拿到新版）。

你手里已有的空条目怎么办

  1. 双击 AniTracker追迹-一键打开.bat（新版已就位，打开后若页面仍旧，按一次 Ctrl+F5 强刷）。
  2. 打开那条空条目的详情页——会看到黄色引导横幅。
  3. 点横幅：已关联 Bangumi 的直接拉齐全集；没关联的会先弹出关联搜索，选对条目点「关联」即自动补齐。
