01 — 为什么以前不行

一道非必要的硬门槛

旧版在搜索入口做了「未粘贴 Bangumi token 时直接拦截」的处理，当时依据是"官方强制鉴权"。实测（双通道验证）：官方搜索接口 POST /v0/search/subjects 支持匿名调用——HTTP 200、CORS 全开、返回完整结果。v2.4 起，搜索与添加不再依赖任何同步配置。

02 — 三种状态

如实说明，不阻断操作

状态表现界面文案
已绑定在线搜索 + 进度可同步「已绑定，可同步进度」
未绑定（可在线）在线搜索照常（公开数据）「免绑定直接搜；绑定仅用于进度同步（可选）」
网络不可用自动降级为本地结果「在线搜索暂不可用——本地结果照常，可正常添加」

04 — 三条添加路径

都不碰同步

路径条件说明
在线添加有网自带 bgmId，之后可直接同步进度
本地库添加无网也行来源记「内置库」；详情页可「⌁ 关联Bangumi」补齐映射
手动添加（＋）零依赖标题 / 集数 / 年份；适合原创番、冷门番、剧场版
05 — 去重、离线与台账

拦截而非静默，断网有出路

  • 重复添加：点击即判（归一化标题 / 同一条目），命中即提示「已在片单」，不产生重复数据。
  • 断网：本地结果照常、提示明确；本地库与手动添加完全离线可用；无白屏、无静默失败。
  • 可追踪：每次添加/关联写入「同步记录」（时间 / 来源 / 对象 / 状态）；最近搜索保留 10 条，可一键清空。
  • 一键回退：同步中心 →「高级设置」可关闭「免绑定搜索」，恢复旧行为；文件级备份 backup_20260914_pre-v24/ + git 提交。
