## 三、差距分级与重设计判定

- **结构性差距（必须处理）**：R1 / R3 / R5 / R9 / R11 —— 属于「体系缺失」，零散修补治不了（19 种字号、32 种间距无法逐处微调收敛，必须建立刻度与令牌后整体映射）。
- **规则性差距（文档+局部修正可解）**：R2 / R7 / R8 / R10 —— 以显式规则 + 组件规范收口。
- **已达标**：R4（大部）、R6（大部）、R12。

**判定：需要重新设计（排版体系级，非整体视觉改版）。** 理由：5 项 P0 级需求「不满足」且均属系统性缺失；按规格要求，必须重建「刻度 → 令牌 → 组件规则 → 响应式」四层体系，并保持现有视觉语言（暖色体系与字体对）不变——即「换骨架、不换皮肤」。

> 重设计边界：不改变信息架构与交互流程；不新增装饰；不引入外链字体；所有改动可映射、可回退。（方案见《排版-重设计方案与实施回滚.md》）
