# 来源标注判定口径（AniTracker v2.3）

> 适用范围：AniTracker「追迹」的**集级**来源标注（原作改编 / TV原创 / 半原创 / 未判定）。
> 版本：v2.3 · 2026-09-14 · 对应 `index.html` 内 `srcInfoOf()` 实现。

## 一、四类标签定义

| 标签 | 内部键 | 含义 |
|---|---|---|
| 原作改编 | canon | 该集内容对应原作（漫画 / 小说 / 游戏等），无已知原创内容 |
| TV原创 | filler | 该集无原作对应内容（动画原创 / 灌水集） |
| 半原创 | semi | 主体走原作剧情，但掺入原创桥段 / 原创过渡（含 AFG "Mixed Canon"）；Bangumi 拉取的特别篇默认归此类、待人工复核 |
| 未判定 | unknown | 没有任何判定依据。**绝不默认按原作改编处理** |

## 二、判定优先级（高 → 低）

1. **人工标注**（`e.src`，用户手动设置，可附备注 `e.srcNote`）—— 最高优先级，永不被自动逻辑覆盖
2. **标题标记**：标题含【动画原创】→ TV原创（若该集已有显式「半原创」标注则保持半原创）
3. **显式数据**：库内/历史数据中写死的 filler / semi / movie
4. **校准区间（AFG）**：`s.filler` 区间命中 → TV原创；`s.mixed` 区间命中 → 半原创；**此时区间外一律按原作改编**（这是唯一允许"默认原作改编"的情形——因为 AFG 已穷举该番的原创集）
5. **系列推断**：整部为原创动画（系列类型 tv-original）→ 该部全集 TV原创
6. 以上全无 → **未判定**

## 三、边界与特例

- **持久性**：标注存于本地数据（`e.src` / `s.filler` / `s.mixed`），刷新、换番、导出/云同步后保持。
- **历史数据迁移**：v2.3 起自动清除旧版本错误写死的 `type:'canon'` 默认值（清除后按真实依据重新判定；无依据即未判定）。迁移幂等、每次启动自动检查。
- **剧场版**：`movie` 标签保持既有语义，不参与 TV原创/半原创 的隐藏筛选。
- **如何修改**：点击任意集行尾部的标签 → 打开标注编辑器；「未判定」选项 = 清除人工标注、交还自动判定。
- **批量操作**：详情页「来源标注 ›」提供：AFG 校准本作 / 仅未判定集批量套用 / 整部批量套用 / 自定义区间批量套用。

## 四、无依据时的处理（重要）

- 无数据支持时一律显示 **未判定**，并在列表行、详情「来源覆盖」行如实展示未判定集数。
- 「未判定」不会被统计进"原作改编"，也不会被筛选隐藏——它提示"这里需要你的注意"。
- 快速消除大批未判定：先跑「批量补齐来源」（列表页筛选条），对仍未覆盖的番使用「整部批量套用」。

## 五、数据来源说明

| 数据 | 来源 | 覆盖 |
|---|---|---|
| 灌水/原创集区间 | Anime Filler Guide 离线快照（`tracker-filler-data.js`，58 部） | 长篇连载为主 |
| 标题【动画原创】 | Bangumi 词条标题 / 内置库数据 | 视具体条目 |
| 系列类型 | 内置推断 `fgType()`（内置库 302 部） | 主要作品 |
| 人工标注 | 你 | 全部 |
