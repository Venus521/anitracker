# 搜索与添加：免绑定能力说明（AniTracker v2.4）

> 面向「不绑定 Bangumi、不经过同步，也能搜索并添加」的完整规则与边界。
> 版本 v2.4.0 · 2026-09-14 · 真身 `http://127.0.0.1:8089`

## 一、为什么以前不行

- 旧版在搜索入口有一道硬门槛：**未粘贴 Bangumi token 时直接拦住搜索**，并弹出同步引导（当时判断"官方强制鉴权"）。
- 实测（2026-09-14，双通道验证）：官方搜索接口 `POST /v0/search/subjects` 支持**匿名调用**（HTTP 200、CORS 全开 `Access-Control-Allow-Origin: *`、可返回完整结果）。「必须先绑定」既非必要，也挡住了正常使用。
- v2.4 起：**搜索与添加不再依赖任何同步配置**；绑定 token 只影响「进度同步」，不影响搜索与添加。

## 二、三种数据状态（界面如实说明）

| 状态 | 表现 | 界面文案 |
|---|---|---|
| 已绑定 | 在线搜索 + 进度可同步 | 「已绑定，可同步进度」 |
| 未绑定（可在线） | 在线搜索照常（公开数据） | 「免绑定直接搜；绑定仅用于进度同步（可选）」 |
| 网络不可用 | 自动降级为本地结果 | 「在线搜索暂不可用（网络问题）——本地结果照常，可正常添加」 |

## 三、搜索：双源结果，来源与新鲜度分区标注

1. **我的片单** —— 标题/日文名模糊命中，点「查看」直达详情；
2. **本地库** —— 内置 302 部快照，**离线可用**，可直接「添加」；
3. **Bangumi 在线** —— **实时数据**（免绑定），点「添加」自动拉取全集。

本地分区即时渲染，在线结果异步补充；别名合并搜索（「海贼王 → ONE PIECE」）沿用既有逻辑。

## 四、添加：三条路，都不碰同步

| 路径 | 条件 | 说明 |
|---|---|---|
| 在线添加 | 有网 | 自带 bgmId，后续可直接同步进度 |
| 本地库添加 | 无网也行 | 来源记为「内置库」；稍后可在详情页「⌁ 关联Bangumi」补齐映射 |
| 手动添加（「＋ 手动添加」） | 零依赖 | 标题/集数/年份；适合原创番、冷门番、剧场版 |

## 五、去重与冲突（拦截而非静默）

- 同一对象（**归一化标题一致** 或 **同一 Bangumi 条目**）重复添加 → 拦截并提示「已在片单：《…》（未重复添加）」；
- 在线结果点「添加」时**先在本地判重（点击即判，不等网络返回）**，命中即提示；
- 关联 Bangumi 时，若目标条目已被其他番占用，同样拦截；
- 内容冲突优先级：本地已有 > 新拉取（拉取采用「只补不删」，另有「完全对齐」开关，见 v2.3 口径）。

## 六、离线体验

- 断网/超时：搜索照常出本地结果 + 顶部明确提示，无白屏、无静默失败、无误报成功；
- 本地库与手动添加完全离线可用；已添加内容立即落本机（刷新/重启保留，随导出/云同步跨设备恢复）；
- 网络恢复后重新搜索即可获得在线结果。

## 七、可追踪：添加台账与最近搜索

- 每次添加/关联写入「同步记录」（同步中心②区）：时间、**来源**（在线搜索/本地库/手动添加/关联 Bangumi）、对象、状态；
- 最近搜索保留 10 条（搜索页「最近」行，可一键清空），随整体导出备份。

## 八、开关与回滚

- 同步中心 →「高级设置」→ 关闭「免绑定搜索」：未绑定 token 时**一键恢复旧行为**（拦截并提示）；
- 开关存于本机 `at_flags.searchNoSync`（默认 `true`）；
- 完整回滚：`backup_20260914_pre-v24/`（上一版本文件）+ git 提交（`详见 部署与回滚说明.md`）。
