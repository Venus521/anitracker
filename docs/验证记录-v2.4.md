## 四、本轮变更清单

- 拆除搜索的 token 硬门槛（实测非必需）；发现依据来自官方接口匿名可用 + CORS 全开；
- 新增双源分区搜索（我的片单 / 本地库 / Bangumi 在线）；
- 新增「＋ 手动添加」（零依赖）与「⌁ 关联Bangumi」（本地番补映射）；
- 在线添加改为**点击即判重**（命中不发请求）；跨源去重（归一化标题 / 同条目）；
- 新增添加台账（4 类来源）与最近搜索（10 条、可清空）；
- 新增「高级设置」开关（一键回退旧行为）与未关联计数。

## 五、未覆盖 / 边界

- 「切换设备后仍可查回」未在真实第二设备演练（需用户云同步凭据）；等价路径（导出/导入、云同步机制）已在 v2.3 验证，风险低；
- 匿名搜索速率策略未单独压测（个人用量足够；如触发限流会按既有重试策略提示）。
