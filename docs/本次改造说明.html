01 — 为什么之前不好用

三个实锤根因，已修复

#问题后果修复
1单集推送走了已废弃的 API 路径 /collections/{sid}/episodes/{eid}单集进度推不上去改为官方 /collections/-/episodes/{eid}
2详情页点选单集传字符串集号，与数字严格比较查不到该路径下集永远不会推送数值化比较 + 回归断言锁死
3_bget 对 204 空响应体执行 r.json()，且任何失败都兜底三个代理写入被拖成约 80 秒后失败容错解析；代理兜底仅限网络层错误

此外，旧逻辑把未标注的集默认写成「漫改」，导致「未判定」被静默算作原作改编、校准数据也被短路——v2.3 起彻底纠正。

02 — 集级来源标注

四类标签与判定口径

原作改编TV原创半原创未判定

判定优先级：人工标注 ＞ 标题【动画原创】 ＞ 显式数据 ＞ AFG 校准区间 ＞ 系列推断 ＞ 未判定（绝不默认算原作改编）。

  • 点击任意集行尾的标签即可改标注；「未判定」＝清除人工标注、交还自动判定。
  • 整部批量：来源标注工具（仅未判定集 / 整部 / 自定义区间）；一键 AFG 校准本作。
  • 列表与详情均显示覆盖：原作 x · TV原创 y · 半原创 z · 未判定 w。
03 — 来源筛选

不想看原创，就真的跳过去

  • 主界面筛选条：「隐藏 TV原创」「隐藏 半原创」开关；刷新与切番保留，一键恢复全部。
  • 隐藏后：集列表过滤、「下一集」跳过、进度统计按可见集计算（界面有口径脚注）。
  • 被排除 ≠ 已看：筛选只改变视图与统计口径，绝不改动观看记录。
