## 六、改造优先级建议（按影响面/工时）


1. **必改 · 高 ROI · 低风险** (~0.5d)
   - 给所有无文本的 `<button>`（纯图标按钮）加 `aria-label`
   - 给所有 `<input>` 加对应 `<label for=...>` 或 `aria-label`
   - 添加 `:focus-visible { outline: 2px solid var(--accent); }` 一条全局规则

2. **应改 · 中 ROI** (~1d)
   - 把所有 `<div onclick>` / `<span onclick>` 改为 `<button type=button>`（或加 `tabindex=0 role=button` + keydown 处理）
   - 给所有 `<input type=password>` 加 `autocomplete=current-password`

3. **慢改 · 高 ROI · 高风险** (~1w)
   - 引入轻量 i18n（推荐 `@formatjs/intl` 或自写极简 key-value + data-i18n 属性）
   - 抽出所有中文文案到 `i18n/zh-CN.json` 与 `i18n/en-US.json`
   - 给弹层 (`.modal` / `.panel`) 加 `role=dialog aria-modal=true aria-labelledby=...`

4. **慢改 · 中 ROI** (~3d)
   - 加 prefers-color-scheme 暗色（替换 JS theme toggle）
   - 给主交互按钮加 min-height:44px（满足 WCAG 2.5.5 AAA / Apple HIG 44pt）
   - 加 prefers-reduced-motion 媒体查询，关掉过渡动画

5. **不建议本轮做**:
   - 全量重写键盘导航（Tab 顺序、Skip Links、Landmark roles）
   - 全量 WCAG 2.2 AAA 审计（工作量大）
