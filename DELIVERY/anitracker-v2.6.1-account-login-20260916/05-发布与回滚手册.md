# 05 · 发布与回滚手册（含演练记录）

## 一、发布方式（本产品适配版）

本产品是**单实例静态应用**（单文件 PWA + 本机静态服务 + CloudBase 托管后端），没有服务器集群，
因此「灰度发布」适配为以下分步放量：

1. **本机验证**（已完成）：无头浏览器专项 10/10 + 回归 19/19；
2. **本机浏览器人工验证**：打开 http://127.0.0.1:8089/index.html → 同步中心 → 账号区显示新版「邮箱」注册入口；
3. **手机端验证**：手机浏览器打开同一入口（服务已监听 0.0.0.0:8089，局域网可访问）；
4. **观察期**：使用 24–48 小时，关注「同步中心 → 同步记录」中的 auth 台账与报错；异常即按下方回滚。

> 注：Service Worker 为 network-first（同源更新即时可达），无需额外发版动作；
> 页面内 `?v=20260916a` 与 `tracker-version.json` 已同步升级，保证不被旧缓存卡住。

## 二、回滚触发条件

- 注册/登录出现阻塞性报错（白屏、卡死、无法提交）；
- 影响既有功能（列表/详情/搜索/同步异常）；
- 页面出现 JS 错误或版本不一致（页面版本 ≠ tracker-version.json）。
