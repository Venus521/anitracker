# 03 · 邮箱登录启用指引（控制台操作 · 约 2 分钟）

> **状态更新（2026-09-16 01:38）：本步骤已由修复会话执行完成** —— 「邮箱登录」已开启，邮箱提供方使用腾讯云默认邮件通道（无需 SMTP），真实全链路复测 9/9 通过。本文件保留作为说明与回退参考。
>
> 原说明：需要在**浏览器里的云开发控制台**完成（应用内已放好直达入口，注册失败时会显示带链接的提示）。
> 启用后，「追迹 → 同步中心 → 账号云同步 → 注册一个」即可全流程使用。

## 为什么需要这一步

修复后的注册流程是「邮箱 + 验证码」（平台唯一支持的注册方式），而当前 CloudBase 环境尚未开启「邮箱登录」能力，
云端会直接拒绝发码请求（实测报错：`provider email not found from endpoint`）。开启它属于环境配置，必须在控制台操作。

## 操作步骤

**第 1 步 · 打开控制台（新窗口）**

👉 [云开发控制台 → 身份认证 → 登录方式](https://tcb.cloud.tencent.com/dev?envId=cloud1-d7gsn5t0w6407b963#/identity/login-manage)

**第 2 步 · 开启「邮箱登录」**（如控制台提供「用户名密码登录」开关，一并开启）

**第 3 步 · 配置发件邮箱（SMTP）**

右侧「配置发件人」→ 填入你的邮箱 SMTP 信息。以 QQ 邮箱为例：

1. QQ 邮箱 → 设置 → 账户 → 开启「IMAP/SMTP 服务」→ 按提示获取**授权码**（一串字母码）；
2. 回到云开发控制台「配置发件人」：发件地址与账号名填你的 QQ 邮箱，密码填**授权码**（不是 QQ 密码）。

**第 4 步 · 应用名称与跳转链接**（可选）

- 「应用名称」会出现在验证邮件里（可填：追迹 AniTracker）；
- 「自动跳转链接」可填 `https://venus521.github.io/anitracker/`（本机调试也可填 `http://127.0.0.1:8089/index.html`）。

**第 5 步 · 保存后自测**

1. 打开追迹 → 同步中心 → 账号云同步 → 「还没有账号？注册一个」；
2. 填邮箱 + 密码（8–32 位、含字母和数字）→ 点「获取验证码」；
3. 若提示「验证码已发送」，去邮箱收信（含垃圾箱），10 分钟内填入 → 完成注册 🎉。

## 快速自检命令（可选）

在项目目录运行：

```powershell
node tests\account-e2e.js
```

- 若 T06 显示 `state: provider-off` → 邮箱登录尚未开启（回到第 1–2 步）；
- 若 T06 显示 `state: enabled` 或提示「验证码已发送」→ 已开启，可继续真实注册。

## 启用后的全链路复测（强烈建议跑一次）

```powershell
node tests\account-live-verify.js
```

该脚本会自动：创建临时邮箱 → 走「注册→收码→验证→绑定用户名→退出登录→用户名登录→邮箱登录→上传/恢复数据」全流程，
并把结果写到 `tests/last-live-verify.json`。全过即为账号链路健康。

## 常见问题

| 现象 | 处理 |
|---|---|
| 收不到验证码 | ①确认第 3 步 SMTP 配置已保存；②查垃圾箱；③等 60 秒重发；④换一个邮箱测试 |
| 提示「用户名已被使用」 | 注册时用户名可留空；注册成功后可在账号区补绑 |
| 提示「操作太频繁」 | 验证码有发送频率限制，等 1 分钟再试 |
| 浏览器打开的页面是旧版 | 关掉页面重开，或用一键启动脚本重新打开（脚本自带防缓存参数） |
