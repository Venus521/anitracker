# 06 · 交接与操作手册（追迹 AniTracker · Bangumi 链路整改后）

> 交付版本：v2.4.4（build 20260915b）· 2026-09-15 · 真身 `D:\项目\01_媒体娱乐\ani-tracker`

## 一、项目现状（3 分钟版）

- 单文件 PWA：`index.html` 是唯一源；`ani-tracker.html` 是脚本同步副本（PWA/旧链接入口）。数据在本机浏览器 localStorage（tr_shows 等），无后端数据库。
- 本地服务：`AniTracker追迹-一键打开.bat`（按需起服 :8089，15 分钟空闲自退，单实例保护）。
- Bangumi 集成：免绑定搜索/添加/补齐 + token 双向同步（拉取/推送/台账/重试/回滚），详见 01 号盘点。
- 本次整改：13 项功能验证保留，6 处缺陷整改，3 处死代码删除（裁决见 03 号）；回归 16/16 全绿（05 号）。

## 二、日常操作

1. **启动**：双击 `AniTracker追迹-一键打开.bat` → 自动开 `http://127.0.0.1:8089/index.html`。手机/PWA 走 GitHub Pages 或同网段 :8089。
2. **绑定 Bangumi**：同步中心 → ① Bangumi 账号 → 按 1 分钟指引在 bgm.tv/settings/services 生成「API 访问令牌」→ 粘贴 → 保存并测试 → 「已绑定：你的用户名」。
3. **同步**：详情页单番拉取/推送；同步中心「拉取全部 / 推送全部」；标记单集自动上行（有 token 时）。出问题看「同步记录」：失败项可「重试失败项」，推送可「回滚本次」。
4. **搜索添加**：搜索框直接搜（免绑定）；未开播条目现在会明确提示并建议「手动添加」。
5. **改完代码必须做**：① 跑 `python 同步双入口.py`（同步 ani-tracker.html）；② 改版本要同时改 index.html 内 AT_VERSION/AT_BUILD 和 tracker-version.json；③ 跑 `运行回归测试.bat`。
6. **测试**：`node tests/run-regression.js`（自起 8094/8092，不出网也不碰真实账号）；模拟器 `tests/mock-bgm-api.js` 支持故障注入（/__ctl）。

## 三、决策记录（本次）

1. 不整体删除 Bangumi 功能：13 项核心链路实测可用；删除将使剧集数据失去来源，违背「不留半成品」。（03 号有彻底删除预案，未执行）
2. 双入口从「手工同步」改为「脚本同步 + 回归锁定」：保留单文件特性与 PWA 兼容，消除漂移（D1 根因）。
3. 网络类错误不再自动重试（限流/5xx 保留 3 次退避）：死网络报错 63.5s→约 20s；代理链降为 5s/跳短超时兜底。
4. 未开播条目：明确提示 + toast + 不入库（此前误导为网络问题）。
5. 拉取时收藏状态/评分以 Bangumi 为准（既有设计，维持不变）；「完全对齐」开关才清除本地多余已看标记。
