## 三、异常路径（保留功能兜底）

- 空数据：空剧集详情页 → 唯一按钮组正常显示（截图 jian-empty-quiet.png）；
- 空筛选结果：剧集区「没有匹配的集（换筛选/关键词试试）」提示保留；
- 网络失败：自动补齐失败回退「✎ 编辑集数」路径不变（busy 分支已同步恢复显示逻辑）；
- 输入错误：搜索无命中 → 空态提示，不崩溃；
- 权限/私密：未涉及（本轮未改账号与云端层）。

## 四、数据链路完整性

本轮只动展示层（隐藏/收纳/文案），未触碰任何数据写入路径：标记进度（tr_shows）、草稿（at_drafts）、台账（at_edit_log）、关联（at_relations）、云端同步（CBSync.autosync）全部原样；回归套件中的 T07（关联双向）、T08（台账）、T02（草稿）全部通过即数据链路完好。

## 五、回滚方式（已实际演练）

| 场景 | 操作 |
|---|---|
| 整体回退本轮简化 | `git checkout HEAD~1 -- index.html tracker-version.json && python 同步双入口.py`（或 `git revert <本次提交>`） |
