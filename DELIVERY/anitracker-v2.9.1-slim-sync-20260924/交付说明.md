## 一、解决什么

你的原话：**「同步还是很累赘」**，并且确认了两点：
- 累赘的地方 = **界面太重、按钮太多**
- 想怎么改 = **一个总开关关掉**

v2.9.0 前后，界面上散着这些同步相关的东西：

| 位置 | 内容 |
|---|---|
| 顶栏 | `⇅ 同步` 按钮 |
| 详情页 | `⟳ 拉取Bangumi进度`、`↑ 推送Bangumi`、`⌁ 关联Bangumi` |
| 同步中心 | Bangumi 绑定卡、同步记录台账、账号云同步、高级设置（免绑定搜索 / 代理说明 / CORS 中继） |
| 各处提示 | 「凭据失效——请在同步中心重新绑定 token」「Bangumi 同步失败…」 |

如果不用 Bangumi，这些全是噪音。

## 二、现在的行为

### 默认状态：精简
打开应用就是干净的样子：

- 顶栏按钮由 **`⇅ 同步`** 变成 **`⇅ 数据`**（title 也改成「数据：本地备份 / 导入导出」）
- 详情页 **不再出现** 拉取 / 推送 / 关联Bangumi 三个按钮
- 点 `⇅ 数据` 打开的面板标题是 **「数据」**，里面只有一个「本地备份（导出/导入）」
- 下面有个折叠项 **「已精简的同步功能」**，点开能看到说明 + **`重新开启同步功能`** 按钮
- **自动推送变为完全静默**：标记一集不会再发 Bangumi 请求，也不会再弹「同步失败」的错误提示

> 关键点：**「本地备份」保留了**。它是纯文件导出/导入，不碰网络、不需要账号，
> 是真正防丢数据的那一层，不算累赘。

### 想用同步时：一键开回
打开 `⇅ 数据` → 展开「已精简的同步功能」→ 点 **`重新开启同步功能`**：

- 顶栏按钮变回 `⇅ 同步`
- 详情页三个 Bangumi 按钮回来
- 面板恢复完整三档：Bangumi 绑定卡 + 同步记录台账 + 账号云同步 + 高级设置（代理说明 / CORS 中继）
- 自动推送恢复

反向操作：`⇅ 同步` → 高级设置 → 最底部 → **`精简掉同步功能（保留本地备份）`**（带确认弹窗，写明会隐藏什么、保留什么）。

## 三、技术实现

### 1. 开关本体
```js
var SYNC_OFF_KEY = 'at_sync_off';
function syncOff()     { /* localStorage 没有值 → 默认 true（精简） */ }
function syncOffSet(off) { /* 写入 '1' / '0' */ }
function applySyncOff()  { /* 改顶栏文案 + 隐藏 [data-bgm-sync] + 设 html[data-sync-off] */ }
```

- **默认值 = 精简（true）**。没有存值就是精简态，符合「累赘就关掉」的诉求。
- 存储是 `localStorage.at_sync_off`（`'1'`=精简 / `'0'`=完整）。**删掉这个键即回到默认精简。**
- 启动时应用：`applySyncOff()` + 两个延时重试（300ms / 1200ms），
  确保 boot 渲染完成后再加样式，避免闪一下完整 UI。

### 2. 单点拦截，而不是改 15 处调用
自动推送散布在 15 个函数里（`bgmPushEp`、`bgmPushStatus`、`bgmPullShow` …），
全都在开头写 `if(!BGMSYNC) return;`。如果逐个加 `syncOff()` 判断，改漏一处就漏一处。

**采用的做法**：改 `bgmTok()` 一个函数——
```js
function bgmTok(){ if(syncOff()) return ''; return (localStorage.getItem('at_bgm_token')||'').trim(); }
```
所有推送函数在拿到 token 后都是 `var tk=bgmTok(); if(!tk) return;`，
所以 token 一空，**全部自动变空操作**，零请求、零报错。一处改动覆盖 15 个调用点。

### 3. 面板按状态渲染
`syncOpen()` 开头取 `var OFF=syncOff()`，然后用三元表达式决定渲染哪些卡片：
- 标题：`OFF ? '数据' : '同步中心'`
- Bangumi 卡 / 台账 / 云同步：仅在 `!OFF` 时输出
- 高级设置（含代理/Bugumi 说明）：`!OFF` 时输出；`OFF` 时改为输出「已精简的同步功能」折叠项
- `bindBgmCard` / `bindAdv` / `renderLedger` / `CBSync.mount` 全部加 `!OFF` 守卫

### 4. 顶栏按钮改名而非隐藏
想了一轮：直接删掉顶栏按钮最干净，但 **「本地备份」也在那个面板里**，
删了就没法导出数据了。所以改成保留入口、改名「数据」——既不误导成「同步」，也不丢备份能力。

## 五、回滚

**改动是纯增量**，数据 100% 不动（关掉的只是 UI 与网络调用，`tr_shows` 等键完全没碰）。

```bash
git revert <本提交SHA>
# 或恢复到 v2.9.0
git checkout b7e5778 -- index.html ani-tracker.html tracker-version.json
```

单独取消精简（回到完整同步 UI，不用改代码）：
```js
localStorage.removeItem('at_sync_off')   // 或设为 '0'
```
删除该键后**默认仍是精简**——若想永久默认完整，需改 `syncOff()` 里的默认返回值。
