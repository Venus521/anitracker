## 一、为什么做这个

v2.8.0 修好了「同步」和「TV原创标注」两件事，但留下一个尾巴：

> Filler 数据集只有 **212 部**（animefillerlist.com 全量）。**新番**和**冷门番**依然查不到，
> 只能靠你手动一集一集标。

这一层的本质是：**任何第三方数据集都追不上新番的更新速度**。
所以需要一个「万能兜底层」——而你提的方案正好是最优解：

> 「我每次要看什么先去 AI 问哪些是原创之类的，然后复制 AI 的话给项目。」

AI 模型本身就知道绝大多数番的 filler 分布（含新番），而且能理解「我只想看漫改部分」这种意图。
把它做成官方入口，就不再依赖任何爬虫源，永久兜底。

## 二、用起来是什么样

### 入口
番剧详情页 → 按钮行里多了一个 **`✧ AI 结果导入`**。
（「来源标注工具」弹窗里也加了同样的入口，两处共用一套逻辑。）

### 三步走
1. 点 `✧ AI 结果导入`
2. 点 **`看看要 AI 怎么说`** → 自动生成一段提问话术，复制去问任意 AI
3. 把 AI 的回答**整段贴回来** → 点 `预览识别` → 点 `写入`

就这三步。**不用整理格式**，随便贴。

### 贴进去能认的写法（实测都通过）

| 你贴的话 | 识别结果 |
|---|---|
| `1-10集为漫改，11-15集是TV原创，16集半原创` | 漫改1-10 / TV原创11-15 / 半原创16 |
| `TV原创：11-15, 23, 45-47` | TV原创 11-15,23,45-47 |
| `1,2,3集是原创` | TV原创 1-3 |
| `第 1、2、3 集是原创；第4集漫改` | TV原创1-3 / 漫改4 |
| `ep1-5 manga canon, ep6 filler` | 漫改1-5 / TV原创6 |
| `原创：45-47 半原创：50` | TV原创45-47 / 半原创50 |
| `1~5集漫改` | 漫改1-5 |
| `第12集：TV原创`（每行一集） | TV原创12 |

**容错**：中英混排、全角半角、有无「第/集/话/ep」、`-`/`~`/`、`/`,`/`/` 分隔都认。

### 识别结果长这样
```
识别结果：TV原创 5 集 · 半原创 1 集 · 漫改 20 集
TV原创：11-15
半原创：16
漫改：1-10,17-26
```

### 认不出来的怎么办（按你的选择）
**能认几条认几条**，认不出的原样列出来，**不阻塞其余写入**：
```
这几条没看懂（不影响其余写入，可自己手动补）：
· TV原创的其他几集我记不清了。
```
纯叙述句（既无分类词也无数字，如「画质很好」）**静默忽略**，不会误报成「没看懂」。

### 冲突怎么处理（按你的选择）
**AI 粘贴的优先**，覆盖自动校准的结果。集级来源会标成 **「AI 导入」**，一眼能看出是手动的还是自动的。
唯一例外：**你真正手改过的集不会被覆盖**（保护人工结果）。

## 三、技术实现要点

### 1. 存储：`at_ai_paste`（新增）
```js
{ "<sid|normTxt(title)>": { f:[…], m:[…], c:[…], at:时间戳, t:番名, raw:原文 } }
```
- 独立于 `at_fg_cache` / `at_fg_live`（那两个是自动抓取的），AI 结果单独一层，**优先级最高**。
- `AT270.aiPasteFor(s)` 取、`AT270.aiPasteClear(s)` 清。

### 2. 判定链新增 `by:'ai'`
`srcInfoOf()` 原来 `by` 只有 `manual / title / data / calib / none`，
现在集对象 `srcNote === 'AI 导入'` 时返回 `by:'ai'`，UI 显示为「AI 导入」而非「人工标注」。
优先级不变（集级标注本来就最高）：**AI/人工 > 标题 > 数据 > 校准 > 待核**。

### 3. 解析器 `AT270.aiParse(text)` —— 核心是「就近归属」
踩过的坑（每个都实测过）：

| 坑 | 现象 | 解法 |
|---|---|---|
| 整行当一句 | `1-10集漫改，11-15集TV原创` 全判成一类 | 按逗号/顿号/分号/斜杠**切子句** |
| 逗号后不继承 | `TV原创：11,12,13` 的 12、13 丢了 | 子句无分类词 → **继承前一个子句**的标签 |
| 后置写法 | `1,2,3集是原创` 只认到 3 | 前面都无词时**向后借**最近子句的标签 |
| 区间正则吃空格 | `45-47 半原创` 的 45-47 误判成半原创 | `m[0].replace(/\s+$/,'')` **去掉尾随空白** |
| 短词抢长词 | `mixed canon` 被 `canon` 抢走 | 去重：被更长词包含的短词丢弃 |

最终规则：**集号先看自己所在子句有没有分类词 → 有就用；没有则取前面最近子句的；前面也没有才向后借。**

### 4. 写入策略
```
1) 逐集落 src 标注（srcNote='AI 导入'），跳过真正手改过的集
2) 若 AI 只给了原创集（没提其余），其余自动按漫改补齐（与 AFG 区间外口径一致）
3) 回写 s.filler / s.mixed 汇总串（列表角标「原创 N」用它）
4) statInvalidate + save + renderDetail
5) logEdit 记一条「AI 导入」到修改历史
```
超范围集号（> 本作集数）**预览时给红字警告，写入时直接丢弃**。

