## 二、右键菜单

### 2.1 三处挂载点

| 挂载点 | 选择器 | 菜单内容 |
|---|---|---|
| 片单卡片 | `.show[data-sid]` | 打开详情 / 标记下一集已看 / 改为「想看·在看·看完·搁置·抛弃」（当前态不重复列出）/ 复制番名 / **从片单移除** |
| 搜索结果卡 | `.sr[data-bgm]` | 加入片单 / 打开详情 / 复制番名 |
| 剧集行 | `.eprow[data-ep]` | 标记已看（或取消已看）/ 标记重看 / **标记到这一集为止**（批量，带确认）/ 改来源标注 / 复制集名 |

### 2.2 两条触发通道

- **桌面**：原生 `contextmenu` 事件。
- **手机**：长按 500ms。手指移动超过 12px 取消（区分滚动与长按）；长按弹出后**吃掉紧随其后的 click**，避免误跳详情页。

### 2.3 体验细节

- 菜单贴近视口右下角时**自动回弹**，不会出界。
- `Esc` / 滚动 / 窗口 resize / 点别处 → 关闭。
- 方向键 `↑↓` 可在菜单项间移动（键盘可达）。
- 标题与文案全部走 `esc()`，脏串不会破坏 DOM。
- 复制：`navigator.clipboard` 为主，`document.execCommand('copy')` 兜底（无权限环境不报错）。

### 2.4 一个必须记下的坑

项目里有**两个 `renderGrid` 实现**：原始版（约 1290 行）和一个 `AT270` 覆盖版（约 3460 行）。
**运行时生效的是 AT270 那个** —— 改错那个等于没改，而且不会有任何报错。

剧集行的 `data-ep` 与 `bindCtx` 必须加在 **AT270 覆盖版**里。第一次就是加错位置，
E2E 报「no eprow」才暴露。已在被覆盖的那份里留注释说明，避免下次再踩。

## 三、重复番剧检测

### 3.1 入口

账号面板 →「片单整理」卡 → 「检查重复番剧」。

### 3.2 双路查重

1. **标题归一化**：`normTxt()` 去掉空格/全角半角/大小写/常见标点后比对。
2. **Bangumi ID**：同一条目被不同名字加过两次，也能抓到。

### 3.3 关键设计：同名组要再细分

**这是本版最重要的一处判断，也是直接回答用户「为什么航海王有两个」的地方。**

朴素做法是「同名即重复」，但那会把正经作品也列进「可移除」清单。实际数据里：

```
海贼王        1999 · 1168集   ← TV 正片
海贼王 剧场版  2000 ·   41集   ← 不同的作品
```

两条都是真的，谁也不该删。所以 `findAllDupGroups()` 在同一标题组内**再按「年份 + 集数」切分**：
只有内容完全一致的子集才算真重复（≥2 条才成组），落单的那份单独放。

### 3.4 报告分三段

| 段落 | 判据 | 有没有「移除」按钮 |
|---|---|---|
| 发现 N 组疑似重复 | 标题、年份、集数都一样 | 有（第一条标「建议保留」） |
| 另有 N 组同条目不同标题 | 同一 Bangumi 条目、标题不同 | 无（提示人工确认） |
| 同名但不同的作品 · N 组 | 标题相同但年份/集数不同，**或标题是前缀关系** | 无，并写「不是重复数据，无需处理」 |

**前缀关系这条是后来补的。** 第一版只比对「归一化后完全相同」，于是
`海贼王` 与 `海贼王 剧场版`（归一化后是 `海贼王` vs `海贼王剧场版`，并不相等）**一条都抓不到** ——
界面就显示「✓ 没有发现重复番剧」，而卡片自己的说明文字还写着「如『海贼王』TV 与『海贼王 剧场版』」，
等于**文案在撒谎**。截图审查时发现（`04-重复检测-只有同名不同作品.png` 第一版是空的）。

补法：两两比对归一化标题，若一方以另一方开头（短的那方 ≥ 2 字符，滤掉「X」这类噪音）即收进该段。
修完后 `04` 截图正确显示「同名但不同的作品 · 1 组」并列出两条。

## 四、顺手修的真实缺陷

**`setEpStat` 在 `statuses` 缺失时崩溃。**

```js
// 旧
function setEpStat(s,n,st){
  var cur=epStat(s,n);
  if(st===null) delete s.statuses[n]; else s.statuses[n]=st;   // ← s.statuses 可能是 undefined
  ...
}
```

对称的 `epStat` 读的时候是安全的（`(s.statuses||{})[n]`），但写的时候没有兜底。
`statuses` 缺失的记录来自：历史版本数据、半写入、外部导入的残缺条目。
这类记录**第一次标记第一集就抛** `TypeError: Cannot set properties of undefined (setting '1')`。

发现路径：E2E check 14 一直失败（菜单关了但一集都没标记上）。加了逐步探针才定位到
`setEpStat` 抛错，异常被 `openCtx` 的调用链吃掉，表面只剩「什么都没发生」。

**修法**：`if(!s.statuses) s.statuses={};` 前置补齐；顺手把 `cntWatched`/`cntRewatch`
从 `for(var k in s.statuses)` 改成 `var o=s.statuses||{}; for(var k in o)`，同样防崩。
