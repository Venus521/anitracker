# AniTracker 追迹 v2.9.3 · 纯记录定位

**日期**：2026-09-25　**版本**：2.9.3 / build `20260925b`

---

## 改了什么

移除了详情页的「**▶ 去门户播放**」按钮，以及它背后的 `playInPortal()` 函数。

**理由**：本作的定位是**观看记录的追踪**——记哪些看了、哪些是原创、进度到哪。
播放跳转不属于这个职责，而且是详情页里**唯一一个把用户带离本页**的按钮
（其余按钮都在本页内完成记录动作）。

## 边界：什么保留、什么移除

| 保留 | 说明 |
|---|---|
| 「B站追番导入」 | 这是**导入**（把你在 B站追的番拉进片单），不是播放 |
| `GW` 网关常量 | 导入链路仍在用，不能连带删掉 |

| 移除 | 说明 |
|---|---|
| `playInPortal()` 函数 | 整个函数删除，注释留档说明原因 |
| 详情页「▶ 去门户播放」按钮 | 之前是强调色（`--accent`）排在第一位 |

## 详情页按钮区（改后）

```
✎ 编辑集数 │ ⟳ 来源校准 │ ✧ AI 结果导入 │ ⟳ 重拉封面
[仅本作关联了 Bangumi 时出现] ⟳ 拉取Bangumi进度 │ ↑ 推送Bangumi
[仅本作未关联时出现] ⌁ 关联Bangumi
```

即：**四个纯记录动作在最前**，同步相关按需出现。整个页面不再有任何跳转到播放的入口。
