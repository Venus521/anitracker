# 排版需求规格（追迹 AniTracker）· v1

> 范围：追迹应用（单页应用，移动优先，`http://127.0.0.1:8089`）。
> 目的：把「排版是否完全符合需求」变成**逐条可判断**的规格与验收口径；本文件是审计与重设计（如需要）的基准。
> 假设与边界：触控优先；浏览器为 Chrome/Edge 近两版；DPR 2 常见；无外链字体（系统字体栈）；暗色模式不在本期；应用当前无导出功能（导出规则见 R13，标注为非目标）。

## 一、用户场景（Why）

| # | 场景 | 排版关注点 |
|---|---|---|
| S1 | 通勤路上单手刷新追番列表 | 触控目标尺寸、列表行高、信息密度 |
| S2 | 快速扫读一部长篇的集列表 | 集行高度一致性、标签不挤压标题、超长标题截断 |
| S3 | 搜索并添加番剧（双源结果） | 结果分区标题层级、按钮触控、来源标注可辨 |
| S4 | 在同步中心核对台账与失败原因 | 卡片/台账行的对齐、等宽数字、错误文案可读 |
| S5 | 长时间阅读统计与进度 | 正文行高、对比度、字号阶梯 |

## 二、功能需求（优先级 P0 > P1 > P2；每条附验收口径）

| ID | 需求 | 优先级 | 验收口径（可判断） |
|---|---|---|---|
| R1 | **字号仅来自 8 级刻度**：44 / 34 / 26 / 20 / 16 / 14 / 12 / 10（px） | P0 | 代码扫描：出现刻度外的 font-size 数 = 0 |
| R2 | **行高配对固定**：每级字号绑定固定行高（正文 1.75，标题 1.35±0.1，展示 1.2） | P0 | 行高取值集合 ≤ 7 个且在规格表内 |
| R3 | **间距为 4 的倍数**：全部 padding/margin/gap 取自间距刻度 4/8/12/16/20/24/32/40/48/64/80 | P0 | 扫描：非刻度间距值 = 0 |
| R4 | **对齐纪律**：4pt 基线；文本左对齐、数字右对齐或等宽；移动边距 20、≥560px 边距 24 | P0 | 抽查 10 处块级元素边距 ∈ {20,24}；数字列采用 tabular-nums |
| R5 | **圆角仅 4 级**：4 / 8 / 12 / 16 / 999（胶囊） | P1 | 扫描：刻度外圆角 = 0 |
| R6 | **触控与行高**：可点元素 ≥44×44；列表行 ≥64 高；chip 高 28；输入高 44 | P0 | 几何抽查通过；360px 宽度下不互相挤压 |
| R7 | **长文本策略**：单行标题省略号 + title 提示；集标题可两行截断；任何文本不得溢出容器或遮挡相邻元素 | P0 | 超长标题（60+ 字）样张：无横向溢出、无遮挡 |
| R8 | **中英数混排**：数字（统计/集数/日期）用等宽数字；中英文混排不加隐形字距；全角标点不出现在行首 | P1 | 混排样张通过；统计数字列对齐 |
| R9 | **响应式**：320–1280px 无横向滚动；窄屏为信息重排（非等比缩小）；对话框/弹层内容自适应 | P0 | 360/460/1280 三档实测：`scrollWidth ≤ clientWidth`；关键入口可见 |
| R10 | **状态完备**：空态 / 加载 / 错误 / 禁用 有统一且可辨的样式 | P1 | 四种状态样张齐全；错误含下一步动作 |
| R11 | **可维护性**：颜色（现有 9 项）与排版刻度全部收敛为 `:root` 令牌；散写内联排版样式清零（白名单除外） | P1 | 内联 font-size 计数从 19 → ≤3；令牌表齐全 |
| R12 | **兼容与性能**：系统字体栈（无外链字体）；CSS 增量 ≤ 8KB；首屏渲染不明显变慢 | P2 | 构建后 CSS 总量与字体请求检查 |
| R13 | 导出一致性（**本期非目标**）：未来若导出 PDF/图片，沿用同刻度；当前应用无导出能力，记为待定 | P2 | 记录在案；不阻塞本期验收 |

## 三、非功能需求

- **NF1 可读性**：正文对比度 ≥ 4.5:1（现有 `--ink`/`--bg` 达标）；正文行宽 ≤ 60 个全角字符（容器 560 内边距后约 38–40 字，达标）。
- **NF2 无回归**：排版调整不得影响任何既有功能（列表/进度/筛选/同步/搜索），数据零改动。
- **NF3 可回退**：以单一文件为单位回退（git revert）；旧样式保留至验收通过。

## 四、默认假设（未提偏好时采用）

1. 可读性、可维护性、一致性优先于个性化装饰；
2. 沿用现有暖色体系（米白/墨色/金棕）与「衬线数字 + 无衬线正文」的字体对，仅重建**结构纪律**（刻度/网格/对齐）；
3. 触控优先，鼠标环境不另做一套尺寸。
