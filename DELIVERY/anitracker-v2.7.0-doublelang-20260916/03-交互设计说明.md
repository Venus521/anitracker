# 03 · 交互设计说明（草稿保护 / 联想 / 编辑流）

## 一、草稿保护（误触空白不再丢内容）

**触发面**：同步中心（含注册/登录/WebDAV 表单）、手动添加弹层、编辑资料弹层、添加关联弹层（白名单机制，见 02 号文档）。

**行为**：
1. 在弹层内填写任何内容后，**点击遮罩空白**或按 **ESC** 关闭时：自动把全部非空输入保存为草稿，并提示「已自动保存草稿，可重新打开一键恢复」；
2. 再次打开同一弹层时，顶部出现横幅「发现 ×× 前未完成的草稿（N 项已保存）→ [恢复草稿] [丢弃]」；
3. 点「恢复草稿」：所有字段一键回填（含触发 input 事件，联动逻辑正常）；点「丢弃」：草稿删除；
4. 字段全空时草稿自动清除；保存成功后可再次编辑（草稿随关闭自动更新）。

**不产生脏条目**：草稿只存字段值，不写任何条目记录；手动添加保存前有必填校验与去重拦截。

## 二、联想（输入候选，一键填入）

| 输入框 | 候选池 | 选中后动作 |
|---|---|---|
| 添加页搜索 `#qKw` | 片单 + 内置库（302 部，含原文名/别名） | 填入名称并立即执行搜索 |
| 详情集筛选 `#qFilter` | 当前番全部分集（集号 + 双语集名） | 填入并刷新筛选 |
| 手动添加 `#at270AddTitle` | 片单 + 内置库 | 填入中文名并预填原文名/年份/集数 |
| 关联目标 `#at270RelKw` | 片单（排除自身） | 选中目标条目 |

- 触发：输入即联想（140ms 防抖）；↑↓ 选择、Enter 确认、Esc 关闭；点击候选项即填入；
- 归一化：候选匹配走 normTxt（大小写/全半角/标点/繁简），「one piece / ONE PIECE / 海贼王 / 航海王」互相可命中。

## 三、编辑流

1. **手动添加**：中文名（必填）→ 原文名 → 别名（多行）→ 年份/总集数 → 保存；重复自动拦截；
2. **编辑资料/别名**：详情页「资料 · 双语与别名」→「✎ 编辑资料 / 别名」；保存时逐字段 diff 并写入修改台账；
3. **集名双语**：详情集行点击「集号」或类型标签 → 编辑器内「集名（双语）」两栏（原文名/中文名）→ 保存后行内第二行即时显示；
4. **来源标注**：同一编辑器上半部（漫改/TV原创/半原创/待核 + 备注 + 范围批量），保持 v2.4.2 语义；每次保存写台账。

**空剧集兜底（去 Bangumi 化，2026-09-16 追加）**：详情页空剧集横幅改为「从内置库补齐」（内置库 302 部命中即带中文集名，无需网络）与「生成第1–N集」占位；列表页「下一集」横幅同接入；「✎ 编辑集数」始终可用。不再提示关联 Bangumi。

## 四、数据质量面板（列表页 ▦ 数据质量）

- 分类占比条（漫改/TV原创/半原创/待核，实时百分比）；
- 双语缺口（缺原文名 N 集 / 缺中文名 N 集）、已校准来源 N/总 部、别名/关联/台账/草稿计数；
- 「待核最多 TOP5」「双语缺口最多 TOP5」，点击直达详情；
- 操作：⟳ 重扫来源（清缓存+批量校准）、⇩ 导出审计 JSON（全量清单）、✕ 清空全部草稿。

## 五、边界状态

| 场景 | 行为 |
|---|---|
| 弹层内全部字段为空时关闭 | 不产生草稿（并清理旧草稿） |
| 草稿对应字段已不存在 | 静默清除该草稿 |
| 重复添加（归一化同名） | 拦截 + 提示「已在片单：《…》」 |
| 关联自身 / 重复关联 | 拦截 + 提示 |
| 预览模式（未加入片单） | 编辑类操作提示先加入片单 |
| 移动端 | 全部为既有 Web 弹层体系的增量，触控可用（无新增悬停依赖） |

## 低门槛与简洁化（2026-09-16 追加）

- **注册只留三步**：邮箱 → 密码 → 验证码；用户名字段已从注册表单移除（CloudBase 用户名规则较严且一个账号只能设一次，改为登录后「帮我生成一个」一键预填，无需记忆任何规则）；
- **详情工具默认折叠**：资料/关联/修改历史收纳进「资料 · 关联 · 修改历史 ▾」一行，点开即用；
- **别名展示收敛**：默认只显示前 3 条（完整列表在编辑弹窗内）；
- 所有报错文案中文化并按真实后端规则提示。
