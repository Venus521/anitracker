# 01 · 根因分析（误触空白退出 · 双语/别名/联想缺失 · 来源分类「一直做不好」）

- 项目：AniTracker 追迹（`D:\项目\01_媒体娱乐\ani-tracker`）
- 日期：2026-09-16
- 版本：v2.6.1 → v2.7.0（本修复）

## 一、问题一：注册/录入点空白处误触退出，内容丢失

**复现（真实环境取证）**：打开同步中心 → 注册视图 → 填入邮箱 + 密码 → 点击遮罩空白处 → 面板立即关闭；`localStorage` 无任何草稿（`at_drafts=null`），内容全部丢失。截图：`assets/probe-repro1-*.png`（修复前后对照）。

**根因**：全站弹层（同步中心 `syncMask`、关联弹层 `assocMask`、来源标注 `srcEditMask` 等）统一使用「点遮罩即关闭」模式：

```js
wrap.addEventListener('click', function(e){ if(e.target===wrap) window.__closeSync(); });
```

且 ESC 也会直接关闭（`escClose`）。注册表单就挂载在 `syncMask` 内，没有任何草稿机制——所以「点空白＝全部白填」。

**修复（v2.7.0）**：注入全局草稿保护层（捕获阶段拦截遮罩点击与 ESC）：
1. 关闭前自动把弹层内所有非空输入存入 `at_drafts`（按弹层 ID 归档）；
2. 给出明确提示「已自动保存草稿，重新打开可一键恢复」；
3. 重新打开同一弹层时出现「发现草稿 → [恢复草稿] [丢弃]」横幅，一键恢复全部已填内容；
4. 草稿只存于本机 localStorage，内容全空时自动清除，不会产生半截脏条目（草稿≠记录）。
实测：28/28 专项测试中 T02a/T02b/T02c 全过（见 05 号文档）。

## 二、问题二：剧名/集名要双语、要别名、要联想——为什么一直缺

**数据层现状（修复前实测，全库 302 部 / 18,513 集）**：
- 剧名：`title`（中文）+ `nameJp`（原文名）**双字段其实早已存在**（302/302 全有原文名），但 UI 只在详情页标题下显示一处，不可编辑、不进检索、列表不显示；
- 集名：每集只有 `t` 一个字段，且中/日文混排（含日文 182 条、无标题 8,342 条），没有「原文名/中文名」分栏；
- 别名：`aliases[]` 存在于 278 部内置库条目，但检索链路只有部分使用（`ownedInList` 不含别名），无编辑入口、无界面展示；
- 联想：全站没有任何输入联想组件。

**结论**：不是「做不出来」，而是**数据字段早已存在、界面层从未接上**——这是「一直做不好」的第一层原因。

**修复（v2.7.0）**：
- 详情页新增「资料 · 双语与别名」区：中文名/原文名/别名 chips 展示 + 「✎ 编辑资料/别名」；
- 集名双语：每集可填「原文名 + 中文名」两个独立字段（`tOrig`/`tCn`），列表行同时显示两种写法，存量数据自动兼容（`t` 保持展示、新旧字段按语言归位）；
- 检索归一化扩展：`normTxt`（大小写/全半角/标点/空白/繁简高频字）+ 别名 + 原文名全部进入检索；`ownedInList` 补上别名链路；
- 联想引擎：搜索框（番剧池）、详情集筛选（集池）、手动添加标题（可预填原文名/年份/集数）、关联目标选择——四处全部接入；↑↓/Enter/Esc 键盘可用。

## 三、问题三：来源分类（漫改/TV原创/版原创…）「一直做不好」

**历史脉络**：v2.3 引入集级来源标注（原作改编/TV原创/半原创/未判定）→ v2.4.2 按用户要求重构为「每集独立四类：漫改/TV原创/半原创/待核」并删除系列级统一分类 → v2.5.1 按用户要求删除了详情页的来源覆盖行/补齐入口/标注入口 → 结果：**分类功能的数据与工具还在，但入口与反馈几乎不可见**。

**根因链（四层）**：
1. **数据覆盖断层**：离线 AFG 快照仅 58 部，且**所有条目的 `m`（混合区间）全为空**——海贼王快照里 `f=92 条、m=0 条`，而海贼王全 1168 集：不跑校准＝全部「待核」；跑了校准＝43 集「混合」也被错归。用户看到的正是「海贼王一大片待核/标错」；
2. **缓存粘滞**：`at_fg_cache` 7 天缓存，即使数据更新也不刷新；
3. **入口与反馈缺失**：v2.5.1 删除详情入口后，「待核」行连编辑入口都没有（类型标签只在有判定依据时渲染）；覆盖报告只有总量、没有按番缺口排行，用户无法知道「差多少、差在哪」；
4. **口径未沉淀**：「漫改/TV原创/半原创」之外，用户提到的「版原创」等词没有官方定义与映射，判定手册缺失。

**修复（v2.7.0）**：
- **数据**：AFG 海贼王条目全量更新（ animefillerlist.com，2026-09-16 抓取）：`f=115`（Filler 94 + Anime Canon 21）、`m=43`（Mixed），**1168 集全覆盖**；快照版本化 `20260916b`，版本变化自动清缓存；
- **自动校准**：更新后首次启动自动跑一次批量校准（海贼王即刻：漫改 1010 / 半原创 43 / TV原创 115，覆盖率 100%）；
- **工具**：新增「▦ 数据质量」面板（分类占比条、双语缺口、别名/关联/台账统计、待核 TOP5、双语缺口 TOP5、一键重扫、审计 JSON 导出）；
- **入口**：每集「集号」即可点击打开编辑器（集名双语 + 来源标注），不再依赖「有标签才能改」；
- **口径**：《04-分类判定手册 v2》固化漫改/TV原创/半原创/剧场版判定与「版原创」候选定义（待业务确认项已标注），附正反例与互斥规则。

## 四、影响面与存量

- 全库 302 部 / 18,513 集：集名缺原文 18,513−182 条级别（按新字段口径）、缺中文 8,342 条（无标题）——这些进入「待补译队列」统计，由数据质量面板持续可见，本次提供工具与抽样审计，不做全量自动清洗（与目标一致）；
- 存量用户数据（`tr_shows`）完全兼容：新字段均为增量，旧版本回滚后仅丢失新增字段显示，不影响既有功能。
