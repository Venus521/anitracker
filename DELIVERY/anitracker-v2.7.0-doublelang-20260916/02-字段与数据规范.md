# 02 · 字段与数据规范（v2.7.0）

> 适用：AniTracker 追迹（单文件应用，数据在 localStorage，云端同步为整包镜像）。
> 本规范是录入/编辑/检索/台账的唯一口径；配合《04-分类判定手册 v2》使用。

## 一、剧集（Series）字段

| 字段 | 类型 | 说明 | 约束 |
|---|---|---|---|
| `sid` | string | 片单内唯一标识（`man-时间戳` / `int-时间戳` /Bangumi 数字） | 不可重复 |
| `title` | string | **中文名（展示名）** | 必填；去重键（normTxt 归一化后比对） |
| `nameJp` | string | **原文名**（日文/英文/罗马字，按官方写法） | 允许为空；为空计入「缺原文名」 |
| `aliases[]` | string[] | **别名列表**，每条可为 `类型: 名称`（台译/港译/旧译/简称/罗马字/英文名…）或纯名称 | 每行一条；去重；检索全量参与 |
| `year` `total` `cover` `status` `statuses` `hist` | — | 既有字段，不变 | — |
| `filler` / `mixed` | string | AFG 校准区间压缩串（如 `54-61,98`），由批量校准写入 | 幂等；可清缓存重算 |

## 二、分集（Episode）字段

| 字段 | 类型 | 说明 | 约束 |
|---|---|---|---|
| `s` | number | 集号 | 唯一键 |
| `t` | string | **展示名**（= 中文名优先，缺省用原文名，再缺省「第 N 集」） | 由编辑器同步 |
| `tOrig` | string | **原文名**（新增） | 可空；为空计入「缺原文」 |
| `tCn` | string | **中文名**（新增） | 可空；为空计入「缺中文」 |
| `src` / `srcNote` / `srcAt` | — | 来源标注（漫改/TV原创/半原创/待核 + 备注 + 时间），v2.4.2 既有 | 人工标注最高优先级 |

- 兼容规则：存量 `t` 保持不变；编辑器保存时按「中文优先」同步 `t = tCn || tOrig || t`；旧版本回滚后只丢失新增字段的显示，不影响功能。
- 双语显示：行内第二行显示「与展示名不同的那一侧」（t=tCn 时显示 tOrig，反之显示 tCn）。

## 三、归一化与去重

- `normTxt`：小写化 + 去除全半角空格/标点 + 高频繁简字归一（内置 160+ 字映射表）；
- 去重：添加/手动添加时 `normTxt(title)` 与片单全量比对，重复即拦截并提示；
- 检索：`title + nameJp + aliases + tOrig + tCn` 全部过 normTxt 后子串匹配；任一写法命中同一条目。

## 四、别名书写约定

```
台译: 航海王
港译: 航海王
旧译: 海盗王
简称: 海贼
罗马字: ONE PIECE
英文名: One Piece
```

- `类型: 名称` 写法会在界面按原样展示（前缀即类型）；纯名称视为「未分类别名」；
- 类型词汇不强制枚举，但推荐使用：台译 / 港译 / 旧译 / 简称 / 罗马字 / 英文名。

## 五、新增存储键

| 键 | 内容 | 说明 |
|---|---|---|
| `at_drafts` | 弹层草稿（按弹层 ID 归档，含字段值与时间） | 白名单：syncMask / at270AddMask / at270ProfMask / at270RelMask；内容全空自动清除 |
| `at_relations` | 关联条目 `[{a,b,type,at}]` | a/b 为 sid；双向查询；解除即删除 |
| `at_edit_log` | 修改台账（cap 300） | `{at, sid, kind, detail, by}`；kind：创建条目/资料编辑/集名双语/来源标注/关联添加/关联解除 |
| `at_fg_snap` | Filler 数据版本标记 | 变化时自动清 `at_fg_cache` 并触发一次批量校准 |
| `at_v270` | 迁移旗标 | 幂等迁移标记 |

- 以上键全部随「导出全部数据 / 云同步」一起迁移（云端同步为整包 localStorage 镜像，白名单之外的键一并上传）。
- 安全说明：草稿按需求「恢复全部已填内容」包含密码字段，仅存于本机与用户自己的云端；**登录/注册成功后自动清理**（清扫周期 6 秒，表单消失即清）。如需更严策略可将密码字段排除（改动点：`collectDraft`）。

## 六、待补译队列（口径）

- **缺原文名**：分集缺 `tOrig`；剧集缺 `nameJp`；
- **缺中文名**：分集缺 `tCn`；剧集 `title` 必填故不存在；
- 统计入口：列表页「▦ 数据质量」面板（实时计算）＋「⇩ 导出审计 JSON」（全量清单）。

## 七、迁移说明

- v2.7.0 全部为**增量字段/增量键**，无删除、无改写既有结构；旧数据首次进入新版本时无需转换即可用；
- 回滚到 v2.6.1：新字段/新键被旧版本忽略（不报错、不影响既有功能），`tracker-filler-data.js` 的海贼王数据更新对旧版本同样生效（只会更准）。
