1. **来源**：Anime Filler Guide（animefillerlist.com/shows/one-piece），该站即本应用 AFG 快照的既有来源（非新增数据源）；
2. **抓取**：2026-09-16，经 AutoGLM open-link 通道获取页面文本（93,582B，1168 行逐集分类+日期）；
3. **解析**：`parse-afg.js`——逐行正则 `^集号 标题 分类 日期$`；分类映射：Filler/Anime Canon → `f`，Mixed Canon/Filler → `m`，Manga Canon → 区间外默认漫改；
4. **写回**：`update-afg270.js`——以 `"one-piece":{...}` 锚点整体替换，文件头注释同步更新；
5. **校验**：
   - 解析 1168/1168 行（0 条未解析）；

## 三、如何扩充其余 56 部（同一方法）

1. 对目标番执行：`python open-link.py "https://www.animefillerlist.com/shows/<slug>" > ref/afg-<slug>.txt`
2. 复制 `parse-afg.js` 改 IN/OUT/OLD 三个路径与 `"one-piece"` 匹配键（slug 见 `tracker-filler-data.js`）；
3. 运行解析 → 检查 `parsed/maxEp` 与旧数据包含关系 → `update-afg270.js` 改写目标键；
4. 把模块 `SNAP` 版本标记递增（如 `20260916c`）——启动时会自动清缓存并重校准；
5. 跑三套测试 + 「▦ 数据质量」确认。

## 四、口径备注

- **Anime Canon → TV原创**：AFG 的 Anime Canon = 动画原创但不偏离主线；本应用口径「TV原创 = 无原作对应内容」将其并入（与旧快照一致）。如需单独区分，需扩展标签集（记录在 04 号文档待确认项）；
- **Mixed Canon/Filler → 半原创**：主体原作+原创桥段；
