## 三、具体改动清单

| # | 改动 | 旧 | 新 |
|---|---|---|---|
| 1 | 触发识别 | 手动点「预览识别」 | **粘贴即自动识别**（防抖 260ms；paste 事件 60ms 快速通道） |
| 2 | 结果呈现 | 三行灰字 | **分类色卡**（点 / 标签 / 集号区间 / 集数右对齐） |
| 3 | 构成感知 | 无 | **占比条**（三类各占一段，宽度=集数占比） |
| 4 | 集数视觉 | 混在文本里 | 右对齐独立列，`font-variant-numeric: tabular-nums` 数字等宽 |
| 5 | 未识别内容 | 正文直出 | 收进 `<details>` 折叠区，标题写明条数 |
| 6 | 超范围提示 | 静默丢弃 | 明确文案「有 N 个集号超出本作范围（共 M 集），不会写入」 |
| 7 | 按钮 | 5 个平铺 | **3 个**：「复制提问给 AI」/（有旧结果时才出现的）「清除已存结果」+ 底部「取消 / 写入」 |
| 8 | 主按钮禁用态 | 无视觉区分 | `disabled` + `opacity:.45`，识别到内容才启用 |
| 9 | 色板 | 无 | 三类专属色，**跟随主题**（深色下换成同色系降饱和版本） |
| 10 | 空/无匹配态 | 无专门处理 | 无匹配时给反例提示，引导重写输入 |

### 配色（暖色系，与全 app 一致）

| 分类 | 浅色 | 深色 | 语义 |
|---|---|---|---|
| TV原创 | `#b4573c` 赤陶 | `#d98a70` | 与「原创」的暖红调一致 |
| 半原创 | `#a8842f` 赭黄 | `#d4b269` | 介于两者之间 |
| 漫改 | `#5f8a5a` 松绿 | `#93bb8c` | 原作向，冷一些 |

色卡底色/描边用 `color-mix(in srgb, <色> 7%/38%, var(--card)/var(--line))` 生成 ——
**底色和描边都是从同一个色变量算出来的**，改主题只需改变量，
不会出现「深色下面板发灰」这种典型翻车。
（`color-mix` 有硬编码 hex 兜底，老浏览器不至于全白。）

## 四、顺带修的 2 个真 bug

### bug 1 · 防抖定时器在面板关闭后触发 → 读 null 崩溃

**现象**：回归测试 `A12` 报 `pageErrors=1`。

**成因**：`queuePreview()` 排了 260ms 的 `setTimeout(showPreview, 260)`。
用户粘贴完立刻关面板（或点「取消」），`wrap` 已被 `remove()`，
但定时器照常触发，`$('at270AiText')` 返回 `null`，读 `.value` 直接抛
`Cannot read properties of null (reading 'value')`。

**修法**：`showPreview()` 开头先判存活，元素没了就静默返回。

```js
function showPreview() {
  /* v2.10.1：防抖定时器可能在面板已关闭后才触发（元素已移除）→ 先判断存活。
     否则会抛 "Cannot read properties of null (reading 'value')"。 */
  var ta = $('at270AiText');
  if (!ta || !wrap.parentNode) return;
  var msg = $('at270AiMsg'), box = $('at270AiPrev');
  if (!msg || !box) return;
  ...
}
```

> 这类 bug 只在「打字/粘贴 + 快速关闭」的时序下出现，
> 手动点几下几乎撞不到，但用户真会这么干。

### bug 2 · toast 浮层遮住面板底部主按钮

**成因**：`#toast` 是 `position:fixed; bottom:34px`，而面板的主按钮
（「写入」）也在屏幕靠近底部的位置 —— 写入成功后的提示，正好盖住刚点的按钮。

**修法**：新增 `body.panel-open` 状态类，面板打开时把 toast 抬高。

```css
/* v2.10.1：面板打开时把 toast 抬到底部按钮之上，避免遮住「写入」等主操作 */
body.panel-open #toast{bottom:96px}
```

**状态怎么同步**：不逐个面板改，而是在 `document.body` 上挂**一个**
`MutationObserver`，只认「页面上还有没有 `.mask`」这一件事。
好处是**以后新加任何面板都自动生效**，不用记得去接线。

```js
(function(){
  var sync=function(){
    try{
      var has=!!document.querySelector('.mask');
      if(has) document.body.classList.add('panel-open');
      else document.body.classList.remove('panel-open');
    }catch(e){}
  };
  try{
    new MutationObserver(sync).observe(document.body,{childList:true,subtree:true});
    sync();
  }catch(e){}
})();
```

（`半原创161 集` 这种串起来根本匹配不准），而是**直接读每张色卡的 DOM**：

```js
const cards = await page.evaluate(() => Array.from(document.querySelectorAll('#at270AiPrev .aicat')).map(c => ({
  label: (c.querySelector('.lbl') || {}).textContent || '',
  range: (c.querySelector('.range') || {}).textContent || '',
```

`漫改==='1-10,17-26'/'20 集'` —— **结构断言比文本断言稳**。

## 六、没改的东西（明确说明）

- **`aiParse` 解析器逻辑不改** —— 这版是交互和视觉，解析行为与 v2.9.0 一致，
  12 项 AI 导入测试里 1/2/6/7/8/9/10/11 全部沿用原断言继续通过。
- **写入优先级不改** —— 仍是「集级标注 > AI 覆盖层 > 无」，
  真正人工改过的集**依然不覆盖**（A9 守着）。
- **兜底口径不改** —— AI 只给了原创集、没提其余时，其余按漫改，
  与 `AFG` 区间外口径一致。
