# AniTracker 追迹 v2.9.2 · 同步改版（按使用频率分层）

**日期**：2026-09-25　**版本**：2.9.2 / build `20260925a`

---

## 为什么又改了一次

v2.9.1 我做的「同步精简总开关」是**错的解法**。

用户的原话是「**精简不是让你藏起来，同步功能怎么做方便**」——意思很清楚：不是要一个
把功能藏起来的开关，而是**同步这件事本身要做得顺手**。

v2.9.1 的问题：默认关掉 → 所有 Bangumi 相关 UI 消失。问题只是被挪到看不见的地方，
用户想用的时候还得先找到开关、再打开、再刷新。**把累赘藏起来 ≠ 消除累赘。**

## 这次的做法：频率分层

累赘的根源是**面板把六块东西平铺在一起，眼睛没有落点**。而这六块的
**使用频率差异极大**——

| 功能 | 多久用一次 |
|---|---|
| 本地备份（导出/导入） | 偶尔，但人人都会用 |
| Bangumi 进度（拉取/推送） | 要用 Bangumi 的人，高频 |
| 账号云同步 | 少数人用 |
| 同步记录台账 | 出问题时才看 |
| 高级设置（代理/中继） | 连不上时才看 |

所以按频率排序，而不是一刀切隐藏：

### ① 顶部一句话状态（新增）

打开面板第一眼就知道现在什么状况：

> **● Bangumi 已绑定 · 上次同步 1 小时前**

未绑定/未同步/云同步已开，都会反映在这句里。不用再翻卡片找线索。

### ② 一个主行动按钮，随状态变（新增）

- 未绑定 → 「**去绑定 Bangumi**」（点了自动滚到绑定卡并聚焦输入框）
- 已绑定 → 「**立即同步进度**」（点了直接推送全部，不用先找按钮）

### ③ 常开档（默认展开）

- **本地备份** —— 导出/导入一个文件，不用账号
- **Bangumi 账号** —— 绑定卡自带引导文案，本来就该直接可见

### ④ 折叠档（默认收起，点开即用）

- 账号云同步
- 同步记录（最近 15 条）
- 高级设置（代理说明 / CORS 中继 / 免绑定搜索）

**折叠状态会被记住** —— 你展开过同步记录，下次打开它还是展开的。
这不是隐藏，只是视觉分层。

## 另外一个真实的累赘：详情页

详情页原本 7 个按钮平铺，其中「拉取Bangumi进度 / 推送Bangumi」**对本地添加的番
一直可见，但点了永远没用**（没有 Bangumi 条目可同步）。

现在：**只在本作真的关联了 Bangumi 时才出现**，并且把日常按钮排到前面：

```
▶ 去门户播放 │ ✎ 编辑集数 │ ⟳ 来源校准 │ ✧ AI 结果导入 │ ⟳ 重拉封面
[再下面：只有关联了 Bangumi 才出现] ⟳ 拉取Bangumi进度 │ ↑ 推送Bangumi
```

## 撤掉的东西

- `syncOff()` 恒返回 `false`，不再有全局隐藏
- `applySyncOff()`、`optSyncOn`、`optSyncOffBtn` 全部移除
- 顶栏按钮从「数据」改回「**同步**」（不再需要掩饰它）
- `bgmTok()` 里的单点拦截已移除 —— 同步链路恢复为默认可用
- 老用户身上若留有 `at_sync_off` 标记，首次打开**自动清除并恢复完整 UI**
